# AI Products

Три AI-продукта — от идеи до готового интерфейса.

Каждый описан отдельно: что делает, почему это реально работает, и как выглядит на практике. Выбирай ниже, либо открой папку продукта за полным описанием (английский `README.md`, русский `README_RU.md`).

## [Forge](./Forge) — опиши продукт, получи сайт за 60 секунд

![Forge](Forge/screenshots/forge-landing-hero.png)

AI-генератор сайтов, превращающий одно предложение-описание продукта в настоящий, готовый к развёртыванию React + Vite сайт — сам подбирает дизайн, пишет тексты и собирает каждую секцию. Без выбора шаблонов, без drag-and-drop редактора.

→ [Подробнее](./Forge/README_RU.md)

## [Shushlaika AI](./Shushlaika%20AI) — загрузи таблицу, разговаривай с ней

![Shushlaika AI](<Shushlaika AI/screenshots/workspace.png>)

Воркспейс для данных, где загружаешь CSV и просишь AI-ассистента проанализировать, почистить или преобразовать данные обычным языком. Сам выбирает подходящий способ под запрос, перед ответом читает твои реальные данные и никогда не перезаписывает — каждое изменение становится новой версией.

→ [Подробнее](<./Shushlaika AI/README_RU.md>)

## [Ground Truth](./Ground%20Truth) — находи инженерные проблемы до того, как они станут очевидны

![Ground Truth](<Ground Truth/screenshots/landing.png>)

Ищет по тысячам GitHub issues, вопросов на Stack Overflow и технических обсуждений повторяющиеся инженерные проблемы — и подкрепляет каждый вывод реальными, связанными доказательствами вместо догадки модели. Подтверждение из нескольких источников и отслеживание трендов отделяют реальные паттерны от шума.

→ [Подробнее](<./Ground Truth/README_RU.md>)
